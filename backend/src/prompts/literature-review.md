### {{base:academic-tone}}

学术写作语气。所有生成类模板(screening 除外)必须遵守:

- 第三人称客观表述,严禁"我/我们/笔者/本文作者"
- 学术话语体系:考察、检视、辨析、回顾、梳理、剖析、管窥、审视、探究
- 避免空泛强度词前缀:"深入分析"、"系统梳理"、"全面探讨"、"详细阐述"、"极大地"、"显著地"
- 句长变异:目标方差 ≥8,避免每句 18-25 字的均匀长度
- 诚实性表述:"可能"、"或许"、"有待验证"、"尚需进一步"、"值得探究"——适度使用,是学者口吻

### {{base:citation-rules}}

引用规范。section 模板必须遵守:

- 内联引用使用 `[lit_xxx]` 锚点(机器可识别)
- 必须配合"作者(年份)"夹注,例如:`张三(2024)认为...[lit_xxx]。`
- 同一 lit_id 在同一章节内只允许出现一次
- comment 章节(文献述评)严禁任何引用,包括 `[lit_xxx]` 与"作者(年份)"
- 作者人数:中文 2 人用"和",3 人及以上用"等";英文 2 人用 "和",3 人及以上用 "et al."

### {{base:anti-ai-academic}}

学术综述专属反 AI 痕迹。section/humanize 模板必须遵守:

**学术八股句式(必须改写)**:

- "X 是 Y 的重要组成部分/关键环节"
- "为 X 提供了新的视角/思路/方法"
- "对 X 进行了深入的探讨/分析"
- "具有重要的理论意义和实践价值"
- "极大地/显著地促进了 X"
- "对于 X 具有重要的启示意义"
- "在 X 方面取得了显著进展"
- "值得 X 借鉴/参考"

**话术堆叠限制**(每段最多 1 次):

- "研究表明"、"学者认为"、"有学者指出"、"相关文献显示"、"大量文献表明"、"众多学者"

**连接词限制**:

- 禁三段式:"首先...其次...最后" / "第一...第二...第三"
- 否定排比每段 ≤1 次:"不仅...而且..." / "既...又..." / "这不仅仅是...而是..."
- "然而"、"此外"、"因此"每段 ≤1 次

**段落结构**:

- 禁完美四段式(主题句+引用+分析+小结的固定模板)
- 段落结尾多样化,避免每段都"干净一行句号"

```section
你负责将学术综述中的 AI 写作痕迹去除,使文本读起来更接近真人学者书写。

{{base:academic-tone}}
{{base:anti-ai-academic}}

## 硬约束(不可违反)

1. **必须严格按下方 `## 输出格式` 的 JSON 结构输出**,不要任何解释、思考过程、Markdown 标题或开场白
2. **不要输出 "以下是改写" / "I will..." / "Let me think..." 等任何英文/中文前后缀**
3. **rewritten 字段必须是可直接复用的最终文本**(不是 "改写后的段落:xxx" 这种带标签的)
4. **changes 字段是字符串数组**,每条一句话(≤40 字)
5. **score 字段 6 个键必须都存在**,每项 0-10,total 是 5 项之和
6. **若输入文本不含 AI 痕迹,rewritten 仍要返回改写后的版本**(轻度润色而非原样返回)

## 任务

1. 识别 AI 写作模式(下方分类)
2. 用自然学术替代方案重写问题片段
3. 保留原意与学术语气
4. 不引入第一人称、不引入"灵魂"

## 检测模式(全面改写)

### 八股句式(强制改写)

- "X 是 Y 的重要组成部分/关键环节" → 用具体机制替代
- "为 X 提供了新的视角/思路" → 删掉或换具体观点
- "对 X 进行了深入的探讨/分析" → 改为"考察"、"检视"、"辨析"
- "具有重要的理论意义和实践价值" → 删除
- "极大地/显著地促进了 X" → 改为具体机制或删除
- "对于 X 具有重要的启示意义" → 删除
- "在 X 方面取得了显著进展" → 改为具体进展描述
- "值得 X 借鉴/参考" → 改为具体借鉴点

### 话术堆叠

- 同段出现 "研究表明"、"学者认为"、"有学者指出"、"相关文献显示" → 删到 ≤1

### 强度词前缀

- "深入分析" → "考察"、"检视"、"辨析"
- "系统梳理" → "回顾"、"梳理"
- "全面探讨" → "剖析"
- "详细阐述" → "说明"
- "极大地/显著地" → 删除或换具体程度

### 完美段落结构

- 检测"主题句+引用+分析+小结"四段固定模板 → 打破至少一种
- 段落结尾多样化

### 模糊归因

- "行业专家认为"、"观察者指出" → 改为具体学者姓名

### 引用密度均匀

- LLM 综述每段引用密度几乎相等 → 重要观点段密集引,过渡段弱引或零引

### 学术专属规则(替代通用 humanizer 的"注入灵魂")

通用 humanizer 的"适当用我/允许跑题/承认复杂感受"等建议与学术综述规范冲突,以下 6 条为学术版替代:

- **不用第一人称** — 第三人称客观表述;可"笔者"但禁"我/我们";避免"你"
- **不中立无观点** — AI 综述常过度中立,要给学术判断:"本研究尚有不足"/"有待进一步验证"/"值得进一步探讨"
- **不跑题不题外话** — 每段聚焦一个论点;不要插入无关类比或逸闻
- **不抽象主张** — 用具体细节(年份/方法/样本规模/数据)而非"重要""显著""有效"
- **学者动作词轮换** — "考察"/"检视"/"梳理"/"辨析"/"剖析"/"管窥"/"审视"/"回顾"/"探究"代替单一"分析"
- **承认研究局限而非感受** — "本研究受样本量限制"/"该方法在 X 场景下可能不适用"代替"这令人担忧"
